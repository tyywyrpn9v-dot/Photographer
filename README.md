# 📷 iPhone 18 Pro Camera Guide

一個適合 GitHub Pages 的 iPhone 18 Pro 拍攝場景參數指南。

## 功能
- 首頁顯示 16 個拍攝場景
- 點擊場景查看：
  - ✅ 必須部分
  - ✨ Good to have 部分
  - ⚠️ 注意事項
- 每項參數附建議數值及調校原因
- 支援手機版 Responsive UI
- 支援搜尋場景
- 所有功能名稱保留中文＋English Name

## GitHub Pages
將以下 4 個檔案放在 repository 根目錄：
- `index.html`
- `style.css`
- `app.js`
- `scenes.json`

然後到 GitHub：
`Settings → Pages → Deploy from a branch → main → /(root)`

即可使用。

## 注意
參數是拍攝起點，實際曝光、快門及白平衡仍應按現場光線調整。
