# iPhone 18 Pro 攝影參數指南

GitHub Pages-ready 的繁體中文 iPhone 18 Pro 攝影場景指南。

## v2 功能
- 📚 全部場景
- ⭐ 常用場景：首頁快速篩選常見拍攝情境
- ❤️ 我的最愛：可在任何場景卡或詳細頁加入／取消最愛
- 🔎 搜尋場景、參數及關鍵字
- ⚡ 每個場景頂部「一眼睇晒」
- 🔴 必須部分／🟢 選項分開；表格不再重複「是否必須」
- 📋 一鍵複製快速設定
- 🎛️ Camera Control 操作順序
- ⚠️ 注意事項
- 📱 Responsive mobile / desktop
- 💾 我的最愛使用瀏覽器 localStorage，不需要後端

## GitHub Pages
將 `index.html`、`style.css`、`app.js`、`scenes.json` 上傳到 repository 根目錄，然後在 GitHub → Settings → Pages 選擇 `main` branch / root。

## 資料
場景資料集中於 `scenes.json`，可直接新增或修改場景。
